    ② 怎么做到的

    STEP 1 · 取数交给 MCP

    通过麦当劳 MCP 拉取历史订单（order-list）、积分（query-my-account）、门店菜单（query-meals）。

    STEP 2 · 算术交给代码

    本地聚合客单价、复购频率、时段、城市轨迹，再用规则引擎算人设标签与绩效评级。

    STEP 3 · 表达交给 Agent

    生成毒舌点评 + 省钱参谋，输出一份可截图分享的述职报告。

    ③ 真实性对照

    项目性质说明
    画像数字（客单价/频率/门店/城市）✅ 真实由 order-list / query-my-account 实时返回
    绩效评级 / 人设标签🟡 娱乐化规则引擎打分，仅供娱乐
    毒舌点评🟡 娱乐化模板 + 真实数据拼装
    省钱建议（麦金卡价差）✅ 真实实测：体验卡 15 天 ¥9.9、四件套 ¥58.5→¥28
    积分数据✅ 真实query-my-account 返回的可用/已过期积分
