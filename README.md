# 麦金卡算师 · mcd-card-roi

> 用你过去一年的真实麦当劳订单，算清「麦金卡」到底值不值 —— 多久回本、省多少、买不买，一句话出结论。

## 它能回答什么

- 我这一年点单花了多少？客单价多少、多久吃一次？
- 如果当时有麦金卡，能少花多少？
- 麦金卡多久回本？我的消费习惯适不适合买？
- 临期积分和可领的券，现在怎么用最不亏？

## 先看输出（示意）

```
┌──────────────────────────────────┐
│  你的麦门年度画像                 │
│  过去 12 个月：58 单               │
│  累计花费：¥ 2,431                 │
│  客单价：¥ 41.9                    │
│  复购频率：每 6.3 天一次            │
├──────────────────────────────────┤
│  麦金卡 ROI                       │
│  若当时有卡，可省：¥ 118           │
│  回本周期：约 1.5 个月             │
│  结论：✅ 值得买                   │
└──────────────────────────────────┘
```

> 上面是示意输出。本项目 v0.1 已打通麦当劳 MCP 链路，正在用真实数据校准字段；卡价、权益以麦当劳官方为准。

## 为什么做这个

麦金卡、早餐卡到底划不划算，凭感觉没人说得清。本项目的答案是**用你自己的历史订单算**，而不是用行业平均糊弄你。结果只对「你」有效，因此天然适合截图分享 —— 这是它能被转发、被收藏的原因。

## 工作原理

1. 通过麦当劳 MCP 拉取你的历史订单（`order-list`）
2. 聚合统计：总花费、客单价、复购频率、时段分布
3. 结合门店菜单（`query-meals` / `query-meal-detail`）与 `calculate-price`，试算「有卡 vs 无卡」的价差
4. 输出回本周期与购买建议，并顺带给出临期积分 / 可领券的处置建议

## 快速开始

前置条件：先申请麦当劳 MCP Token（https://open.mcd.cn/mcp ，手机号登录 → 控制台 → 激活）。

```bash
# 1. 设置 Token 环境变量
# Linux / macOS
export MCD_MCP_TOKEN=你的token
# Windows PowerShell
$env:MCD_MCP_TOKEN="你的token"

# 2. 跑通（零依赖，仅需 Node >= 18）
npm run probe   # 列出全部可用工具与参数
npm run roi     # 生成你的麦金卡 ROI 报告（v0.1 为数据探路版）
```
