# 麦金卡算师 · mcd-card-roi

> 用你的真实麦当劳订单，算清「麦金卡」到底值不值 —— 多久回本、省多少、**以及你或许根本不需要买**。

## 它能回答什么

- 我点单花了多少？客单价多少、多久吃一次、最爱哪家店？
- 如果当时有麦金卡，能少花多少？多久回本？
- 我的点法（单人随心配 vs 四件套）到底适不适合买卡？
- 积分有没有白过期？临期积分现在怎么用最不亏？

## 为什么做这个

麦金卡、早餐卡到底划不划算，凭感觉没人说得清。市面上的「省钱助手」只会告诉你「有券快领」；本项目反其道而行 —— **用你自己的历史订单算，并敢于给出「你可能不需要买卡」的结论**。结果只对「你」有效，因此天然适合截图分享。

实测到的麦金卡机制（来自麦当劳 MCP 真实返回）：

- **麦金卡体验卡（15 天）随单购 ¥9.9**
- 解锁「四件套」专属价，例如板烧鸡腿堡四件套 `¥58.5 → ¥28`，单套省 ¥30.5
- 扣掉卡费后，**15 天内点 1 次净省约 ¥22、点 2 次净省约 ¥54**

## 工作原理

1. `order-list` → 拉取历史订单（含商品明细、金额、门店、时间）
2. 本地聚合：总花费、客单价、复购频率、时段分布、最爱门店、常点餐品
3. `query-my-account` → 积分档案，含已过期/临期积分止损提醒
4. `query-meals` → 读取门店菜单里带「麦金卡优惠」的品项及价差
5. 结合卡价（¥9.9/15天）输出回本测算与购买建议

## 快速开始

前置条件：先申请麦当劳 MCP Token（https://open.mcd.cn/mcp ，手机号登录 → 控制台 → 激活）。

```bash
# 1. 设置 Token 环境变量
# Linux / macOS
export MCD_MCP_TOKEN=你的token
# Windows PowerShell
$env:MCD_MCP_TOKEN="你的token"

# 2. 跑通（零依赖，仅需 Node >= 18）
npm run probe   # 列出全部可用工具与参数
npm run roi     # 生成你的麦门消费画像 + 麦金卡 ROI 报告
```
